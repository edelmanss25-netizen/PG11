# ФОРМАТ — печатный планировщик (с облачной синхронизацией)

Статический сайт без сборки: `index.html` + `config.js`.
Данные синхронизируются между телефоном и компьютером через Supabase.

## 1. Supabase (один раз)
1. supabase.com → New project (бесплатный тариф подходит).
2. SQL Editor → New query → вставьте содержимое `supabase.sql` → Run.
3. Authentication → Sign In / Providers → Email: для личного использования отключите
   «Confirm email» (иначе после регистрации нужно подтвердить адрес по письму).
4. Authentication → URL Configuration → Site URL: адрес вашего сайта на Vercel
   (например `https://format.vercel.app`) — нужен для ссылок из писем.
5. Project Settings → API: скопируйте Project URL и ключ `anon public`.

## 2. Конфиг
Откройте `config.js` и впишите URL и ключ.

## 3. Vercel
Загрузите папку (GitHub или перетаскиванием в Add New → Project). Framework Preset: Other,
сборка не нужна. Через CLI: `npx vercel --prod`.

## 4. Использование
Откройте сайт на каждом устройстве → «☁ Войти» → один и тот же email и пароль.
Данные, уже записанные на устройстве, при первом входе загрузятся в облако и объединятся с облачными.

## Как это работает
- Приложение сначала сохраняет всё на устройстве, затем отправляет изменения в облако —
  оно работает без сети и догоняет, когда связь вернётся.
- Изменения с другого устройства приходят сразу (realtime) и при возвращении на вкладку.
- Синхронизация по дням. Если один и тот же день правили на двух устройствах без связи, встречи,
  задачи и продажи объединяются, а числа в «Направлениях» остаются с того устройства,
  где их правили.
- Позиция просмотра (какой месяц открыт) на устройствах независима.
- «Выйти» удаляет данные с этого устройства, в облаке они остаются.
